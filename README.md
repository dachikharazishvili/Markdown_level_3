# Command line Cheatsheet





**Commands that are used in Markdown**

**`mkdir` is used to create a folder 📁 that you could name what ever you would like**

here is the example for you:

*      mkdir folder3

and then you could just name it whatever you would like

___

**Now if you want to create a file 🗃️ you have to use `touch` with *.md* and *.txt* for files**

here is the example for it:

*     cd folder(go in the folder first that you want to create the file in) 
      touch file.md touch file2.txt

___

**Now if you want to list all the folders that are already in the directory you have to use `list`**

This is the example for you to see:

*      ls 
       output would be this for you: folder3 file.md file2.txt

___ 

**Now if you want to delete a file, you need `rm <file>`**

My example for this would be:

*     rm <folder3>

___

**Now if you want to remove your folder you would use `rm -rf <folder>` to remove it**

this is my example for it:

*     rm -rf <folder3>
